## ADDED Requirements

### Requirement: Estado de entrega y backlog coherentes

La documentación de estado SHALL mantener coherentes README, niveles de entrega, AGENTS, changelog, Jira y fuentes NotebookLM. Un criterio solo podrá presentarse como verificado si enlaza evidencia reproducible; un criterio planificado SHALL mostrar su dependencia y estado sin convertirse en una afirmación de entrega.

#### Scenario: Actualización tras un corte de MVP

- **WHEN** se prepara una release local del MVP
- **THEN** los documentos principales muestran el mismo conteo de criterios, el mismo alcance local y el mismo mapa de trabajo pendiente
