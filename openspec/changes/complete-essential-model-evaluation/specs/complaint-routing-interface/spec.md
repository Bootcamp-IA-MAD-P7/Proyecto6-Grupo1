## ADDED Requirements

### Requirement: Compatibilidad documentada con candidato esencial local

Cuando ClaimVox se configure para usar el servicio local, la documentación SHALL
identificar el artefacto esencial evaluado que satisface el contrato de
predicción, sin alterar la revisión humana ni presentar la integración como
despliegue.

#### Scenario: Guía de integración local

- **WHEN** una persona sigue la guía de ejecución local
- **THEN** encontrará el comando para reconstruir el artefacto, iniciar el
  servicio y configurar la PWA sin exponer narrativas ni credenciales
