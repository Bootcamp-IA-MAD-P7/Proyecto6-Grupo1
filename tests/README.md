# Pruebas

- `unit/`: funciones y componentes aislados.
- `integration/`: interacción entre datos, modelo, persistencia y aplicación.
- `contract/`: esquemas de entrada/salida y compatibilidad de artefactos.
- `e2e/`: flujos completos y smoke tests.
- `security/`: controles automáticos de seguridad aplicables al sistema.
- `performance/`: tiempos, carga y límites operativos acordados.

La estrategia concreta y los umbrales se definirán en las specs correspondientes.
