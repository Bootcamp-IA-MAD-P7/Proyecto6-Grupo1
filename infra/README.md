# Infraestructura

- `docker/`: imágenes, composición y scripts de arranque.
- `cloud/`: recursos y configuración reproducible de despliegue.
- `environments/`: diferencias explícitas entre staging y producción.

Las subcarpetas se crearán cuando se apruebe e implemente el plan correspondiente. Este README describe el destino previsto y no representa infraestructura implementada.
