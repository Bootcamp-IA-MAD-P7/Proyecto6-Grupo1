# Informes y evidencias

- `figures/`: visualizaciones finales reproducibles.
- `metrics/`: resultados estructurados de experimentos.
- `validation/`: smoke tests, revisiones manuales y evidencias de entrega.

Los informes deben identificar dataset, split, versión de código y versión de modelo.

Las rutas `figures/` y `metrics/` se crearán cuando exista la primera evidencia correspondiente. `validation/` ya contiene las comprobaciones reproducibles disponibles.
