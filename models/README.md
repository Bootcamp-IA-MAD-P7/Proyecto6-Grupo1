# Artefactos de modelos

```text
baseline/     referencia inicial
challengers/  candidatos comparables
champion/     modelo aprobado para inferencia
registry/     metadatos, versiones y compatibilidad
monitoring/   perfiles de referencia para monitorización
```

La política de versionado de binarios se decidirá antes de guardar artefactos grandes. Los metadatos y resultados reproducibles sí deberán quedar trazados.
