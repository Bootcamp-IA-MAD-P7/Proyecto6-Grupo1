# Descubrimiento de producto

Esta carpeta conservará la evidencia utilizada para seleccionar y definir la idea de negocio.

- Problemas candidatos.
- Usuarios y tareas.
- Disponibilidad y calidad de datos.
- Viabilidad de tres o más clases.
- Riesgos éticos y de privacidad.
- Capacidad de demostrar valor mediante una aplicación.

La primera decisión importante del proyecto será elegir una idea mediante criterios explícitos, no por disponibilidad inmediata de un dataset.

## Método vigente

- La [matriz de evaluación](idea_evaluation_template.md) contiene las puertas críticas, escala, pesos, evidencia mínima y mecanismo de aprobación vigentes.
- La versión `1.0` fue aprobada por mayoría absoluta del equipo activo el 22 de julio de 2026.
- Jira mantendrá el estado operativo; las specs y decisiones versionadas seguirán siendo la fuente de verdad del alcance.
