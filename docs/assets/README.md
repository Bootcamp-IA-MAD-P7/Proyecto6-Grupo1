# Recursos documentales

- `brand/`: logotipo, paleta y recursos de identidad aprobados.
- `diagrams/`: diagramas exportados y sus fuentes editables.
- `charts/`: gráficos destinados a documentación y presentaciones.
- `screenshots/`: capturas reales y versionadas del producto.

Estas rutas se crearán al incorporar el primer recurso aprobado; no se mantienen carpetas vacías como evidencia de trabajo.

No se utilizarán recursos visuales genéricos de IA.
