# Estándar visual de documentación

## Objetivo

Crear documentación profesional, escaneable y reutilizable en presentaciones sin convertirla en una colección decorativa de elementos visuales.

## README e informes

Deben combinar, cuando aporten información:

- diagramas de flujo o arquitectura;
- tablas comparativas;
- gráficos generados a partir de datos reales;
- capturas del producto;
- bloques de estado y enlaces destacados;
- paleta y jerarquía tipográfica coherentes.

## Uso del color

- Definir los colores como tokens antes de aplicarlos de forma dispersa.
- Mantener contraste accesible.
- No depender solo del color para expresar estados.
- Utilizar colores de marca o de función, no degradados tecnológicos genéricos.

## Recursos prohibidos

- Robots o humanoides como representación de IA.
- Cerebros digitales.
- Circuitos decorativos.
- Chispas, estrellas o magia para representar automatización.
- Imágenes generadas sin relación directa con el producto.

## Recursos recomendados

- Diagramas propios.
- Visualizaciones de datos reales.
- Fotografía contextual relevante, si la identidad lo necesita.
- Capturas reales y anotadas.
- Iconografía funcional consistente y accesible.

## Trazabilidad

Cada gráfico debe indicar fuente, fecha y versión de los datos. Cada captura debe corresponder a una versión verificable de la aplicación.
