# Diseño y experiencia de usuario

El diseño se tratará como una disciplina transversal desde la definición del producto.

- `ux_principles.md`: reglas de experiencia y accesibilidad.
- `documentation_visual_standard.md`: calidad visual de README, informes y presentaciones.
- `design_system.md`: contrato provisional de tokens y componentes; la identidad visual sigue pendiente.
- `information_architecture.md`: flujo, contenidos y estados de la experiencia propuesta.

La implementación experimental debe diferenciar siempre mocks, contratos y capacidades integradas. La identidad visual definitiva y el flujo B2B requieren validación antes de considerarse cerrados.
