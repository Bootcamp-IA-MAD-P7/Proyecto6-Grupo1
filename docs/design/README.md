# Diseño y experiencia de usuario

El diseño se tratará como una disciplina transversal desde la definición del producto.

- `ux_principles.md`: reglas de experiencia y accesibilidad.
- `documentation_visual_standard.md`: calidad visual de README, informes y presentaciones.
- `design_system.md`: tokens provisionales de la PWA y evolución hacia una identidad visual validada.
- `information_architecture.md`: flujo, estados y jerarquía de la experiencia vigente.

La PWA mock permite validar una hipótesis de usuario, tareas y datos de entrada sin presentarla como producto definitivo. Las nuevas pantallas o áreas de producto requieren una necesidad aprobada en su spec antes de implementarse.
