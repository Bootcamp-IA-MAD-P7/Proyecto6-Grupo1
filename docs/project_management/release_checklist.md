# Checklist de release

## Alcance

- [ ] Specs incluidas cerradas y verificadas.
- [ ] Cambios pendientes movidos a otra spec o descartados con motivo.
- [ ] Changelog actualizado.

## Calidad

- [ ] Tests y builds correctos.
- [ ] Métricas consistentes con informes.
- [ ] Validación manual de flujos críticos.
- [ ] Accesibilidad y responsive revisados.

## Seguridad y operación

- [ ] Sin secretos ni datos sensibles expuestos.
- [ ] Dependencias y contenedores revisados.
- [ ] Migraciones verificadas.
- [ ] Backup y rollback preparados.
- [ ] Observabilidad y alertas activas.

## Documentación y comunicación

- [ ] README actualizado.
- [ ] Diagramas y capturas corresponden a la versión.
- [ ] Fuentes de NotebookLM revisadas.
- [ ] Presentaciones no prometen más de lo implementado.
- [ ] Guía de operación y soporte actualizada.

## Publicación

- [ ] Release PR mergeado en `main`.
- [ ] Despliegue y smoke test correctos.
- [ ] Tag anotado creado.
- [ ] GitHub Release publicado.
- [ ] Evidencia del release registrada.
