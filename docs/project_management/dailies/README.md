# Dailies del equipo

## Convención

Cada jornada tendrá un único documento:

```text
YYYY-MM-DD.md
```

Ejemplo:

```text
2026-07-22.md
```

Todos los documentos mantienen este orden fijo:

1. Resumen del equipo.
2. José.
3. Abel.
4. Víctor.
5. Miguel.
6. Decisiones, riesgos y evidencias comunes.

La daily del 22 de julio de 2026 conserva el apartado de Josué como registro histórico del cambio de composición comunicado ese día. Las dailies posteriores incluyen únicamente al equipo activo.

## Reglas

- Registrar hechos, no planes retrospectivos inventados.
- Enlazar specs, tareas, PR, métricas o documentos cuando existan.
- Mantener los bloqueantes visibles hasta que se resuelvan.
- Trasladar decisiones duraderas a una spec o ADR; la daily no sustituye ese registro.
- Utilizar esta daily canónica directamente como una de las fuentes del paquete de NotebookLM, sin crear copias paralelas.

La plantilla se encuentra en `_template.md`.
