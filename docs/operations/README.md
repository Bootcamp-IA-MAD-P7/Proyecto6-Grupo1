# Operaciones

Esta carpeta contendrá los procedimientos necesarios para ejecutar y mantener el producto:

- despliegue y rollback;
- migraciones;
- backup y restauración;
- observabilidad y alertas;
- respuesta a incidentes;
- soporte y retirada del servicio.

Los runbooks se probarán en staging antes de considerarse válidos para producción.
