# Respuesta a incidentes

## Prioridades

1. Proteger personas y datos.
2. Contener el impacto.
3. Restaurar el servicio de forma segura.
4. Conservar evidencia.
5. Comunicar hechos confirmados.
6. Aprender sin culpas y corregir causas.

## Flujo

```text
Detección -> clasificación -> contención -> recuperación -> verificación -> retrospectiva
```

## Registro mínimo

- Hora de detección.
- Impacto y servicios afectados.
- Versión desplegada.
- Acciones y responsables.
- Evidencias.
- Decisión de rollback.
- Resolución y seguimiento.

Los canales, severidades y responsables se definirán antes del primer despliegue público.
